# Sain Case 4 — Эксперт как плейлист

Серверная часть решения. Пользователь выбирает эксперта и получает ответы, опирающиеся
на базу научных статей; эксперт не даёт диагнозов, лечения и дозировок.

## Запуск

Как развернуть и запустить серверную часть на стенде одной командой.

Окружение стенда: Python 3.11, зависимости из `requirements.txt`, без GPU. Порт — из
переменной окружения `PORT` (на стенде 8000).

```bash
pip install -r requirements.txt
bash start.sh
```

Сервер слушает `0.0.0.0:${PORT}`, отвечает на `GET /` (пинг стенда) и `POST /run`.

Переменные окружения (на стенде уже заданы организаторами):

| Переменная | Назначение |
| --- | --- |
| `HACK_API_URL` | базовый URL API сервиса хакатона; по нему запрашивается набор |
| `HACK_TEAM_TOKEN` | токен команды (для разработки) |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | прокси нейросети и модель |
| `PORT` | порт сервера (на стенде 8000) |

Значения и коды наборов — в README архива команды (`team02/README.md`). Ключи
(`api.token`, `llm.key`, `id_ed25519`) не коммитятся и не выводятся; при локальной
разработке запуск выполняется из папки, где лежит `api.token` (или через env).
