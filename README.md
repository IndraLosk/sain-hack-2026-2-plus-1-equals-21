# Sain Case 4 — Эксперт как плейлист (версия с БД)

Серверная часть решения хакатона Sain × Школа 21, кейс 4. Пользователь выбирает
эксперта и получает ответы, опирающиеся на базу научных статей; эксперт не даёт
диагнозов, лечения и дозировок.

## Запуск локально (с базой, через Docker)

Нужен Docker. Одна команда поднимает Postgres и приложение:

```bash
make up
```

При первом запуске создаётся схема, в БД загружается `case4-dev.json`, затем сервер
поднимается на `http://localhost:8000`.

Список всех команд — `make help`.

## Запуск на стенде (без Docker)

Стенд разворачивает серверную часть по `requirements.txt` и `start.sh` (Python 3.11,
без GPU):

```bash
pip install -r requirements.txt
bash start.sh
```

Сервер слушает `0.0.0.0:$PORT` (на стенде — `8000`) и отвечает на `GET /` и `POST /run`.

Переменные окружения на стенде задаются организаторами:
`HACK_API_URL`, `HACK_TEAM_TOKEN`, `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`, `PORT`.
Локально их можно задать вручную (значения и коды наборов — в README архива команды).

## Работа с базой

Удобнее всего через Makefile:

```bash
make seed          # схема + загрузка case4-dev.json
make reset         # очистить и залить заново
make status        # число строк по таблицам
make health        # проверка подключения к БД
make psql          # консоль Postgres внутри контейнера
make logs          # логи контейнеров
make down          # остановить контейнеры (данные сохраняются)
make reset-hard    # полный сброс данных и пересборка
```

Внешний доступ к Postgres (например, pgAdmin): порт `5434`, учётные данные — в
`docker-compose.yml`.

## Проверка

После запуска:

```bash
curl http://localhost:8000/            # {"service":"sain-case4","status":"ok"}
```

Ответ `/run` формируется по контракту кейса: на вход `{"case": 4, "dataset_code": "..."}`
+ заголовок `Authorization: Bearer <токен>`, на выходе `Case4Answers`.

> Примечание: эта копия держит локальную базу для разработки. На стенде набор приходит
> через `getData`, поэтому БД не является обязательной частью деплоя.
