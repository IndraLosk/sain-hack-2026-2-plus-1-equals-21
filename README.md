# SAIN Hack 2026 · Кейс 4 «Эксперт как плейлист»

Команда **team02** (`sain-hack-2026-2-plus-1-equals-21`).

Приложение: пользователь выбирает одного из трёх экспертов (сомнолог-клиницист, биохакер-экспериментатор, нутрициолог здравого смысла) и получает от него ответ по базе из 20 научных статей о сне. Эксперт не ставит диагнозы, не назначает лечение и не называет дозировки; в ответ на небезопасные запросы (атаки) он мягко отказывает, предлагает безопасную альтернативу и даёт ссылку на статью и раздел базы.

## Запуск

Серверная часть — FastAPI-приложение. Стенд собирает её по `requirements.txt` и запускает по `start.sh`.

```bash
bash start.sh
```

`start.sh` запускает `uvicorn` на `0.0.0.0` и порту из переменной окружения `PORT` (по умолчанию 8000):

```bash
exec python3 -m uvicorn backend.main:app --host 0.0.0.0 --port "${PORT:-8000}"
```

Переменные окружения (на стенде уже заданы, на ноутбуке выставляются вручную):

- `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` — прокси нейросети сервиса (OpenAI-совместимый API);
- `HACK_API_URL`, `HACK_TEAM_TOKEN` — API сервиса хакатона;
- `PORT` — порт HTTP-сервера (на стенде 8000).

Файл `.env` не требуется: приложение читает настройки из окружения. Список всех настроек — в `env.example`.

Клиент — React-приложение в `frontend/`. В рабочем репозитории лежит собранная версия (`frontend/dist`), которую раздаёт серверная часть на том же порту. Пересборка:

```bash
cd frontend && npm install && npm run build
```

Основные эндпоинты:

- `GET /api/v1/catalog` — каталог программ и экспертов;
- `POST /api/v1/chat/stream` — ответ одного эксперта (SSE);
- `POST /api/v1/chat/stream-multi` — один вопрос всем экспертам;
- `POST /run` — демо-стенд кейса 4: на вход набор запросов, на выход ответы с цитатами;
- `GET /api/v1/health` — состояние LLM, векторного хранилища и базы.

## ИИ

- `gpt-6-luna` — единственная модель в проде: генерирует ответы экспертов по фрагментам базы и работает медицинским фильтром безопасности (guardrail) в `backend/llm.py`. Обязательное условие: обращение только через прокси сервиса по токену, свои ключи и веса моделей запрещены.
- `deepseek-chat` — резервный провайдер для локальной разработки и отладки, в проде на стенде не используется.
- Для помощи в разработке применялись сторонние ИИ-инструменты (deepseek-код-ассистент и др.); в работающее решение они не входят.

## Журнал решений

1. **Эмбеддинги BAAI/bge-m3 → BM25.** Изначально планировали векторный поиск с эмбеддингами bge-m3 на ONNX. Отказались после перечитывания инструкции: на стенде нет интернета в runtime, а скачивать веса и ставить модели из контейнера запрещено условиями (Д5). Перешли на лёгкий BM25-Okapi на чистом Python — без внешних моделей и скачиваний (`backend/vectorstore.py`).
2. **PostgreSQL → SQLite.** Рассматривали `postgresql+asyncpg` как основное хранилище. Отказались по инструкции: на стенде ограничение памяти 512 МБ и одна команда на контейнер; PostgreSQL для масштаба кейса избыточен. Остановились на SQLite (`aiosqlite`), переход на PostgreSQL оставлен через `DATABASE_URL`.
3. **Docker → нативный запуск через `start.sh`.** Пробовали оформлять серверную часть как Docker-образ. Отказались: стенд собирает приложение по общему шаблону из `requirements.txt` + `start.sh` и свой `Dockerfile` не использует.
4. **Аватары экспертов → упрощённая подача.** Планировали проработанные аватары для трёх экспертов как отдельный UI-блок. Отказались: идея признана устаревшей и нагружающей; различия экспертов подаются текстом и стилем ответа, как того требуют критерии (V — различимость по тексту, а не по картинкам).
5. **Интерфейс, перегруженный кнопками → минимализм.** В первой версии главный экран содержал много элементов (источники, память, рекомендация статей и др. в одном ряду). Отказались от перегрузки: вернулись к простой схеме «выбор эксперта — лента сообщений — строка ввода», второстепенные функции убрали в отдельные панели.
6. **Одна модель → резервный провайдер.** Приложение изначально строилось только на `gpt-6-luna`. Добавили переключение на `deepseek-chat` как резерв для разработки и на случай недоступности основной модели; на стенде конфигурация по умолчанию остаётся за `gpt-6-luna`.
