# Sain Case 4 — Эксперт как плейлист

Серверная часть решения. Пользователь выбирает «программу» (плейлист) и персону эксперта,
а агент отвечает строго по научным статьям из векторной базы: не ставит диагнозы, не назначает
лечение и не называет дозировки.

## Запуск

Как развернуть и запустить серверную часть на стенде одной командой.

Окружение стенда: Python 3.11, зависимости из `requirements.txt`, без GPU. Порт — из переменной
окружения `PORT` (на стенде 8000).

```bash
pip install -r requirements.txt
bash start.sh
```

Сервер слушает `0.0.0.0:${PORT}`, отвечает на `GET /` (пинг стенда) и `POST /run`.

Локально (для разработки) можно запустить через `./run.sh` — команда создаст `.venv`,
установит зависимости и поднимет uvicorn на `http://127.0.0.1:8000`. Встроенный UI — на `/`,
Swagger — на `/docs`.

Переменные окружения (на стенде уже заданы организаторами):

| Переменная | Назначение |
| --- | --- |
| `HACK_API_URL` | базовый URL API сервиса хакатона; по нему запрашивается набор данных |
| `HACK_TEAM_TOKEN` | токен команды (для разработки) |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | прокси нейросети и модель |
| `PORT` | порт сервера (на стенде 8000) |

Ключи (`api.token`, `llm.key`, `id_ed25519`) не коммитятся и не выводятся. Значения и коды
наборов — в README архива команды.

Статьи для RAG-базы загружаются из `data/case4-dev.json` при первом старте в ChromaDB
(`data/chroma/`), эмбеддинги — через `sentence-transformers` (`BAAI/bge-m3`).

## Архитектура

```
app/
  main.py        FastAPI: /api/v1/catalog, /api/v1/chat/stream (SSE), /api/v1/articles, /health, /run
  agent.py       LangGraph-граф: retriever → guardrail → (safe_redirect | expert_response)
  vectorstore.py ChromaDB + bge-m3 + чанкование + гибридный ранжинг со свежестью
  llm.py         OpenAI-совместимый клиент (chat/stream/json) + guardrail (LLM + эвристики)
  config.py      Pydantic-настройки и валидация config/catalog.json при старте
  schemas.py     Pydantic-схемы запросов/ответов и событий SSE
config/catalog.json      программы и персоны экспертов (стиль задаётся через system_style_prompt)
data/case4-dev.json      статьи для сидирования RAG-базы (при первом старте)
data/chroma/             постоянная векторная база ChromaDB
web/index.html           лёгкий UI: витрина программ, переключатель экспертов, SSE-чат
```

### Граф агента

```
START → retriever_node → guardrail_node ─┬─ unsafe → safe_redirect_node ─→ END
                                         └─ safe   → expert_response_node ─→ END
```

- **retriever_node** — Chroma-запрос с фильтром `program_id`, топ-3 чанка, бонус свежести,
  максимум 2 чанка на статью, фолбэк на всю базу.
- **guardrail_node** — LLM-проверка с JSON-структурой (`SafetyCheckSchema`) + детерминированные
  эвристики (мг/мл/капли/таблетки, «сколько пить», схема приёма, отмена назначений, диагноз).
  Эвристика имеет приоритет — guardrail не «промолчит».
- **safe_redirect_node** — мягкий отказ, выжимка из статей и один поведенческий шаг.
- **expert_response_node** — промпт из изолированных блоков `[FACTS_ONLY]` (чанки + дата) и
  `[PERSONA_STYLE]` (стиль персоны). Пустой контекст → фиксированная фраза «В моей
  доказательной базе пока нет подтверждённых исследований по этому вопросу».

Состояние диалога (тред) хранится в чекпойнтере (`AsyncSqliteSaver`, `data/checkpoints.sqlite`),
поэтому переключение персоны не сбрасывает историю.

### API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/v1/catalog` | программы + эксперты |
| POST | `/api/v1/chat/stream` | SSE-поток ответа |
| GET | `/api/v1/chat/history?session_id=` | история диалога из чекпойнтера |
| DELETE | `/api/v1/chat/history?session_id=` | сброс диалога |
| POST | `/api/v1/articles` | куратор: 202 Accepted, индексация в BackgroundTasks |
| GET | `/api/v1/articles` | список статей в базе (с бейджем `is_new`) |
| DELETE | `/api/v1/articles/{article_id}` | удалить статью из базы |
| GET | `/api/v1/health` | статус LLM/Chroma/модели |
| POST | `/api/v1/admin/reseed` | пересобрать базу |
| POST | `/run` | контракт стенда кейса 4 → `Case4Answers` |

SSE-события чата: `safety_flag`, `sources`, `meta`, `token`, `done`.
